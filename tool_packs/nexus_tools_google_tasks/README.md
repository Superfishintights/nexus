# nexus_tools_google_tasks

Nexus tools for Google Tasks API v1.

Install:

```bash
pip install -e .
```

Enable with `NEXUS_TOOL_PACKAGES`:

```bash
export NEXUS_TOOL_PACKAGES="nexus_tools_google_tasks"
```

This pack depends on `nexus-tools-google-common` for Google OAuth and HTTP
request handling.
